# Lab Report Explainer

Python (Flask) backend + plain HTML/CSS/JS frontend.

## Run
```
pip install -r requirements.txt
python main.py
```
Open http://127.0.0.1:5000

## Check the rules engine against the answer key
```
python main.py --check
```

## Structure
```
main.py            Flask server + rules engine + answers
requirements.txt
frontend/          index.html, styles.css, app.js
docs/              answer_key.csv, test_questions.md
```
Only a licensed doctor can diagnose.
